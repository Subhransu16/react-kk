# React Assignment: useReducer & Lazy Loading

This project includes Tasks 1–9 from the supplied assignment.

## Requirements
- Node.js (LTS recommended)
- npm

## Run the project
1. Extract the ZIP file.
2. Open a terminal in the `React_UseReducer_LazyLoading_Assignment` folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
```

## Included tasks
1. Counter Application — useReducer and action types
2. Increment by Custom Value — action.payload
3. Show / Hide Password — boolean reducer state
4. Student Form — object reducer state
5. API Fetch Users — FETCH_START, FETCH_SUCCESS, FETCH_ERROR
6. Fetch Users with Search — case-insensitive filtering; search managed by useReducer
7. Todo Application — add, delete, complete/pending, total count
8. Lazy Load About Component — React.lazy and Suspense
9. Lazy Load Student Details — conditional lazy loading and Suspense

The user list tasks use the JSONPlaceholder API and require an internet connection.
